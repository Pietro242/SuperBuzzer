# SuperBuzzer

Applicazione per quiz musicali in tempo reale con sistema di prenotazione (buzzer) e WebSocket server locale.

## 🐛 Problemi Noti (Bugs)
- **Caricamento lento:** Le manche che contengono immagini risultano lente nel caricamento.
- **Sicurezza:** Sono presenti problemi di sicurezza generici (da revisionare).

---
*Progetto creato inizialmente con React + Vite.*
