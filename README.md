# SuperBuzzer

Applicazione per quiz musicali in tempo reale con sistema di prenotazione (buzzer) e WebSocket server locale.

## 🐛 Problemi Noti (Bugs)
- **Aggiungere rumore buzzer nell'apertura del buzzer e quando buzza il primo giocatore**
- **rumore di errore quando sbaglia la risposta**
- **creare readme:** Sono presenti problemi di sicurezza generici (da revisionare).
